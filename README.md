# Signal Shop

A simple digital store. Edit `config.js` only, then push to Vercel.

## Deploy
1. Import this repo into Vercel as **Other** (no build).
2. Open `config.js` and replace the Stripe placeholder links with your real payment links.
3. Change product names, prices, or descriptions if you want.
4. Push.

The page updates automatically.

## What you change
Only the values inside `config.js`:
- Brand name
- Product list (name, price, description, Stripe link)

Everything else stays the same. No servers, no build step, no extra setup.
